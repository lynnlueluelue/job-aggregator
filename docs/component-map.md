▉ 页面整体结构（从上到下） ▉
──────────────────────────────
HEADER 顶栏          : 页面最顶部，固定吸顶不滚动。
HERO 封面区          : 第一个屏幕，大标题+统计的展示区。
BOOKMARKS 常驻入口书签 : "知名企业热招"，横向轮播卡片。
筛选条件折叠条        : 点击展开/收起下面的筛选面板。
STATS 统计条         : 一排状态徽章，如"显示 96/512 条"。
LIST 公告列表        : 公告分组卡片与单条卡片。
FOOTER 页脚          : 页面底部免责声明。
右下角 FAB           : 右下角悬浮圆形搜索按钮。
TOAST 提示           : 左下角短暂弹出的操作反馈。
MODAL 弹窗           : 居中的数据更新提醒对话框。

──────────────────────────────
▉ HEADER 顶栏内部构件 ▉
──────────────────────────────
header             : 顶栏整体容器。
h1 标题            : "考编公告聚合"标题文字。
.meta 元信息       : "更新 xx｜共 x 条｜每3小时"。
.actions 按钮组     : 右侧一排按钮容器。
.btn 普通按钮       : 灰色描边圆角按钮（清空搜索等）。
.btn.primary 主按钮 : 蓝色实心主按钮（立即刷新）。

──────────────────────────────
▉ HERO 封面区内部构件 ▉
──────────────────────────────
.hero              : 封面区整体容器（背景渐变）。
.hero-inner        : 封面内容居中容器。
.hero-tag 小标签    : 上方"考编·{地区}"小字（随生成变化）。
.hero-title 主标题  : 大标题"找到适合你的体制内机会"。
.hero-highlight    : 主标题中高亮的关键词。
.hero-sub 副标题    : 说明性文字段落（含渠道数）。
.hero-stats 数据条  : 渠道/公告/已排除/梯队统计。
.hero-stat         : 单个统计项（数字+标签）。
.hero-card 情报卡   : 右侧"情报概览"白色卡片。
.hc-head 卡标题    : "情报概览"标题。
.hc-grid 卡网格    : 4 个数字格子的网格。
.hc-item 数字格    : 单个格子（第一/二/三梯队、高分精选）。
.hc-num 数字       : 格子内的大数字。
.hc-label 格标签   : 格子内的小文字。
.hc-foot 卡底部    : "上次更新"那一行。
.hero-scroll 下滑提示: 底部"↓下滑浏览"。
.stats-panel 统计卡组 : 右栏实时动态卡片（2列网格）。
.sp-card 统计卡片   : 统计面板中的一张卡片。
  .sp-card.blue     : 蓝色渐变卡（今日新增·文字数字卡）。
  .sp-card.light    : 浅蓝底卡（今日新增·柱状图卡）。
  .sp-card.list-card: 全宽卡（最新发布列表）。

──────────────────────────────
▉ BOOKMARKS 书签区内部构件 ▉
──────────────────────────────
.bm-carousel-wrap 书签区容器 : 横向轮播整体包裹。
.bm-head-stitch 标题行 : "知名企业热招"标题行。
.bm-carousel-inner 轮播套件 : 内含滚动容器+右滑按钮。
.bm-carousel 滚动容器 : 书签卡片横向滚动列表（隐藏滚动条）。
.bm-scroll-btn 右滑按钮 : 标题行右端圆形"›"按钮，点击右滑260px。
.bm-count 数量     : 标题行右侧 "N 个" 文字。
.bm-card 单张卡片   : 单个入口链接卡片（宽130px）。
.bm-card-icon 图标区: 卡片图标/字母方块（48px圆角）。
.bm-card-name 名称  : 卡片名称文字。
.bm-card-url 域名   : 卡片域名小字。

──────────────────────────────
▉ 筛选面板内部构件 ▉
──────────────────────────────
.filter-toggle 折叠条 : "筛选条件"按钮，显示已激活数。
.filter-panel 面板   : 展开后的整个筛选面板。
.fd-bar 下拉条      : 横排 4 个下拉触发器的一行。
.fd-trigger 下拉触发器 : 单个药丸按钮（图标+名称+▾）。
  .fd-icon          : 触发器图标。
  .fd-label         : 触发器名称文字。
  .fd-arrow         : 触发器箭头（打开时旋转180°）。
.fd-body 下拉面板   : 点击触发器展开的全宽下拉面板。
.fg-chip 条件胶囊   : 下拉面板内的选项（全部/待办等）。
  .fg-chip.active   : 选中态（浅蓝底+蓝字+蓝描边）。
.exclude-toggle 排除开关 : 红色系开关（×中小学教师岗等）。
.track-input 追踪输入 : 求职追踪考试名称输入框。
.track-add 添加按钮  : "＋追踪"按钮。
.track-chips 追踪胶囊 : 已追踪考试的胶囊列表。
.custom-add-input 添加输入: 自定义公告链接输入框。
.custom-add-btn 添加按钮: "＋添加"按钮。

──────────────────────────────
▉ STATS 统计条构件 ▉
──────────────────────────────
.stats           : 统计条容器。
.sbadge 状态徽章  : 单个统计项（显示x条/待办/已排除等）。

──────────────────────────────
▉ LIST 公告列表内部构件 ▉
──────────────────────────────
.channel-group 分组卡 : 按渠道/梯队分组的整块卡片。
.channel-head 组标题  : 组标题（含梯队标签+来源名）。
.tier-tag 梯队标签    : 组标题前的彩色小标签。
.cnt 数量          : "x 条"文字。
.item 单条公告卡     : 一条公告的整体卡片。
.item-num 梯队号码条 : 左侧彩色竖条，显示梯队号/★。
.item-body 正文区   : 中间文字区域。
.item-title 标题    : 公告标题（可含高亮词）。
.item-sub 副标题    : 地区·梯队·方式一行小字。
.item-bottom 标签行 : 底部一排小标签。
.tag 小标签        : 类型标签（考试公告/事业单位/日期等）。
.item-actions 按钮列 : 右侧竖排按钮区。
.ia 动作按钮        : 单个按钮（去投递/标记完成）。

──────────────────────────────
▉ 浮动控件构件 ▉
──────────────────────────────
.search-fab 悬浮按钮 : 右下角搜索按钮容器。
.fab-btn 圆形按钮   : 圆形搜索按钮。
.search-pop 搜索弹层: 点击后弹出的搜索面板。
#q 搜索输入框      : 弹层内标题搜索框。
#filters 渠道胶囊  : 弹层内渠道筛选胶囊。
.ctx-menu 右键菜单  : 右键点击公告弹出的菜单。
.toast 提示        : 左下角操作反馈提示。
.modal-mask 遮罩   : 弹窗的灰色背景遮罩。
.modal 弹窗        : 居中的白色对话框。
