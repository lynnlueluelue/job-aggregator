## 一、设计语言总览

| 维度 | 方案 |
|---|---|
| 设计风格 | **Stitch 原型风**：大留白、浅色渐变、圆角卡片、药丸胶囊、柔和阴影 |
| 主色调 | 强调蓝 `#2F6FBA` / 深海军蓝 `#1D4ED8` 渐变（Hero 搜索按钮、数据面板） |
| 页面背景 | 浅灰蓝渐变 `#F4F7FA → #EDF2F8`（固定背景） |
| 字号体系 | 大标题 42px → 副标题 16px → 正文 14px → 辅助 11–13px |
| 圆角体系 | 卡片 14–16px、胶囊 20–24px、图标 10–12px |
| 阴影体系 | 卡片悬浮 8px/16px、面板 20px、按钮 hover 提升 2px |

  --good      #2E7D5B   成功绿

  --tier2     #5B8FD4   二梯队

  --tier4     #2E7D5B   四梯队

**关键搭配**：
- Hero 搜索按钮：`#2F6FBA → #1D4ED8` 渐变、白字、右圆角 24px（输入框左圆角，形成连体搜索条）
- 数据面板 `sp-card.blue`：蓝渐变底 + 白字大数字（今日新增）
- 高亮关键词：`#2F6FBA`（主标题内"体制内机会"）
- 大面积留白 + 极浅描边 `#DCE6F0`，避免高饱和度压迫感

## 三、HEADER 顶栏

- **布局**：`header-top` 弹性排列（logo｜元信息｜按钮组三列，可换行）
- **Logo**："考编"深色 + "公告聚合"强调蓝 16px 加粗，右侧灰色副题（生成：地区 · 省份 · 考试通道）
- **元信息**：`更新 -- | 共 -- 条 | 每 3 小时`，灰色小字
- **按钮组**：主按钮"立即刷新"（蓝底白字 + loading 旋转态）、"只看高分"、"清空搜索"（描边药丸）
- **样式**：白底吸顶 `sticky`、底部细描边 + 16px 柔和阴影、z-index 50

## 四、HERO 首屏（核心改版）

结构：`hero` 渐变背景（白 → `#DCEBF9`）占满首屏 → 内部左右两栏。

### 4.1 左栏 `hero-text`
| 构件 | 方案 |
|---|---|
| hero-tag 小标签 | "考编 · {地区}" 强调蓝 13px，字距 1px |
| hero-title 主标题 | "找到最适合你的 / 体制内机会" 42px 800，高亮词蓝色 |
| hero-sub 副标题 | 说明文字 16px 灰色，行高 1.7（含渠道数，随生成变化） |
| **hero-search 搜索条** | 输入框（左圆角 24px）+ "快速搜索"按钮（右圆角 24px 蓝渐变），聚焦蓝色光晕，实时联动右上角 FAB 搜索弹层（`oninput` 同步 `#q` 并 `render()`） |
| hero-stats 数据条 | 渠道 N / 公告 -- / 已排除 -- / 梯队 N，数字 22px 加粗 |

### 4.2 右栏 `stats-panel`（实时招聘动态与趋势）
2 列网格，前两张卡片并排，第三张全宽：

| 卡片 | 内容 |
|---|---|
| sp-card.blue | **今日新增公告**（文字数据）：蓝色渐变卡，白字大数字 `+N`（JS 按日期实时统计） |
| sp-card.light | **今日新增公告**（柱状图）：浅蓝底 `--accent-bg`，5 根蓝色圆角柱（纯 CSS，模拟近 5 天） |
| sp-card.list-card | **最新发布**：全宽，`#spLatestList` 动态渲染最近 3 条公告（蓝点 + 标题截断 24 字），JS `updateHeroStats()` 填充 |

### 4.3 动效
- `heroFadeUp`：hero-text（.1s）与 stats-panel（.25s）从 `translateY(24px) + opacity:0` 淡入上浮
- 右下柔光圆 `::before`：`rgba(47,111,186,.10)` 径向渐变装饰
- 底部"↓ 下滑浏览"：`scrollBounce` 上下弹跳动画，点击平滑滚动到列表
- 移动端（<768px）：左右栏纵向堆叠，标题降为 30px

## 五、常驻入口（横排书签轮播）

- **标题行** `bm-head-stitch`："**知名企业热招**" 16px 加粗 + 右侧数量提示 `N 个`
- **右滑按钮** `bm-scroll-btn`：标题行右端圆形白底按钮（"›"），点击平滑右滚 260px（JS `scrollBookmarks()`）
- **容器**：`display:flex; overflow-x:auto`，隐藏滚动条，卡片横向排布、hover 上浮
- **卡片** `bm-card`：固定宽 130px、居中布局
  - 图标区 `bm-card-icon`：48px 圆角方块，favicon 在线提取，失败回退首字母 + `BM_COLORS` 八色池
  - 名称 `bm-card-name`：13px 加粗，单行截断
  - 域名 `bm-card-url`：10px 灰色，单行截断
- **渲染**：JS `renderBookmarks()` 按 tier 排序循环生成

## 六、筛选条件（横排下拉面板）

### 6.1 折叠条 `filter-toggle`
- "筛选条件" + 已激活数量徽标（`ft-badge`，默认隐藏、有激活项时显示）+ 箭头 ▾/▴
- JS 变量 `filtersOpen = true`，**默认展开面板**；点击切换 `collapsed` 类

### 6.2 面板常驻行（面板顶部）
- **自定义添加**：粘贴公告链接 + 可选标题 + "＋ 添加"
- **求职追踪**：考试名称输入框 + "＋ 追踪" + "显示全部公示"开关 + 已追踪计数

### 6.3 横排下拉（fd-bar）
一行内 4 个药丸触发器，每个含图标 + 名称 + ▾ 箭头：

| 触发器 | 展开内容 |
|---|---|
| 标记 | 全部 / 待办 / 已办 / 已删去 |
| 单位类型 | 全部 / 事业单位 / 高校 / 国企 / 央企 / 其他 |
| 发布时间 | 全部 / 近3月 / 近1月 / 近1周 / 近3天 / 当日 |
| 更多条件 | 排除开关组、已追踪胶囊、投递方式、校招/社招、地区（生成：目标省份城市）、招聘对象、年龄上限、党员要求、专业对口、条件核对说明 |

- **下拉行为**：点击 `fd-trigger` 切换 `open` 类（箭头 180° 旋转）+ 对应 `fd-body` 显示；`fd-body` 为绝对定位**全宽下拉面板**（`left:0; right:0`）；同时只开一个；点击面板外区域自动全部关闭
- **定位关键**：`fd-body` 依赖 `fd-bar{position:relative}` 作定位祖先；`.filter-section` **不能设 `overflow:hidden`**（会裁掉绝对定位的下拉，08-11 已修复），圆角只设在 `.filter-toggle` 上、打开态改顶部圆角 + 底边框衔接面板
- **选中态** `fg-chip.active`：浅蓝底 + 蓝色字 + 蓝色描边 + 加粗
- JS `pick()` / `isChipForKind()` 已适配 `fd-body` 结构（按 `fd-trigger .fd-label` 匹配分组）

## 七、其他区域

- **统计条** `#stats`：彩色胶囊徽标行（显示数/总数、待办、已排除、政策新闻、隐藏公示、已删去）
- **公告列表** `#list`：第一梯队合并大卡片 + 其余按梯队→渠道分组；白底圆角条目，左侧 tier 色竖条/星标，右侧"去投递/标记完成"文字按钮；右键菜单（复制原网址/删除）
- **右下 FAB + 搜索弹层**：悬浮圆形搜索按钮，弹出面板含标题搜索框 + 渠道来源胶囊
- **骨架屏 / Toast / 刷新弹窗 / 右键菜单**

## 八、设计原则备忘

1. **一屏一焦点**：Hero 全屏首屏只做"搜索 + 数据概览"两件事
2. **信息密度控制**：常用筛选默认展开、低频条件折叠进"更多条件"
3. **状态可读性**：选中/排除/待办均有文字 + 颜色双重表达
4. **动效克制动**：只保留入场淡入 + hover 上浮 + 箭头旋转三类微交互
5. **图表零依赖**：趋势图用内联 SVG、柱状图用纯 CSS，无第三方库
6. **移动端降级**：Hero 堆叠、书签保留横滑、分组面板不受影响
